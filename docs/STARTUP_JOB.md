# Initial Autonomous Job

This is the first job of the top-level agent after reading the repository doctrine.

## Objective

Bootstrap the minimum operating system required to autonomously discover and evaluate lawful revenue opportunities starting from zero.

The agent must not ask the owner what business to build. It must begin the discovery process itself.

## First program of work

### A. Establish durable operating state

Create the minimum structures needed for:
- opportunity register;
- experiment register;
- decision memory;
- rejected-idea memory;
- task/agent state;
- deployment records;
- reflections.

Begin simple if needed. Versioned Markdown/JSONL/SQLite is acceptable during bootstrap if migration is planned.

### B. Establish the first autonomous research loop

Create a process that can:
- scan candidate opportunity classes;
- gather current primary-source evidence;
- score opportunities consistently;
- create falsification experiments;
- persist results;
- reprioritize automatically.

The initial candidate universe should be broad enough to avoid tunnel vision. It may include decentralized financial infrastructure, developer APIs, data products, automated services, and other lawful digital opportunities.

### C. Establish the minimum engineering loop

Create the ability to:
- spawn or route scoped specialist tasks;
- modify the repository safely;
- run tests;
- create isolated experiments;
- record evidence;
- build containerized components when useful.

### D. Establish observability before meaningful deployment

Before relying on a deployed system, ensure the root agent can retrieve:
- health;
- logs;
- metrics;
- version/deployment identity;
- economic outcomes where applicable.

### E. Produce the first opportunity register

For each candidate include:
- mechanism;
- who/what pays;
- automation potential;
- capital requirement;
- expected time to falsification;
- major dependencies;
- competition;
- legal/compliance friction;
- expected unit economics;
- current confidence;
- next experiment.

Rank the register and begin the cheapest high-information experiments.

## DEX-specific instruction

Decentralized exchanges are a preferred area to investigate because they are programmatic and machine-native, but do not assume they are profitable.

Research at least the distinction between:
- same-chain atomic opportunities;
- multi-pool routing/triangular opportunities;
- inventory-based cross-venue strategies;
- cross-chain strategies with bridge/finality exposure;
- non-trading protocol/data opportunities.

Do not conflate visible spread with executable net edge.

## Stop conditions

Do not stop merely because:
- one opportunity failed;
- a prototype works;
- a simulation shows profit;
- the first architecture is imperfect.

Continue the autonomous loop unless:
- a required owner-only authority is reached;
- the Governor requires authorization;
- no safe next action is available;
- an incident requires human intervention.

If owner authorization is required, present a concise decision packet with evidence and continue all independent work that does not require that authority.

## First milestone

The bootstrap milestone is achieved when the repository contains a functioning autonomous kernel capable of repeatedly:

`discover → rank → hypothesize → experiment → record → reflect → reprioritize`

and the system can begin building the highest-value validated opportunity without the owner supplying implementation tasks.
